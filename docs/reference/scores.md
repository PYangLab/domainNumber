# Scores

Read runs back and score them against the ground truth. These calls need only `kdb_py`.

| Name | Summary |
|---|---|
| [`kdb.read_clusters`](#kdomainbench.read_clusters) | Read the domains of one run. |
| [`kdb.ground_truth`](#kdomainbench.ground_truth) | Read the ground-truth domain of each spot. |
| [`kdb.evaluate`](#kdomainbench.evaluate) | Score one run against the ground truth. |
| [`kdb.load_results`](#kdomainbench.load_results) | Collect every run under a folder into one table. |
| [`kdb.k_accuracy`](#kdomainbench.k_accuracy) | Summarize how well each method estimates k. |
