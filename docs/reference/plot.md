# Figures

`kdb.pl` draws the benchmark's figures with matplotlib. Each function returns its axes or figure.
These calls need only the `kdomainbench` package, not the method environments.

| Name | Summary |
|---|---|
| [`kdb.pl.plot_k_estimates`](#kdomainbench.plotting.plot_k_estimates) | Plot the estimated k of each method against the reference domain number. |
| [`kdb.pl.plot_metrics`](#kdomainbench.plotting.plot_metrics) | Plot the metrics of each method as a matrix of bars. |
| [`kdb.pl.plot_runtime`](#kdomainbench.plotting.plot_runtime) | Plot run time or memory per method. |
| [`kdb.pl.plot_spatial`](#kdomainbench.plotting.plot_spatial) | Plot the spatial domains of one run. |
| [`kdb.pl.plot_spatial_grid`](#kdomainbench.plotting.plot_spatial_grid) | Plot the spatial domains of several runs in a grid. |
