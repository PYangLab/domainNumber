# Run

Run methods, each in its own environment. Needs the environments from
[Installation](../installation.md).

| Name | Summary |
|---|---|
| [`kdb.run`](#kdomainbench.run) | Run one method on one `.h5ad` file and return its spatial domains. |
| [`kdb.run_all`](#kdomainbench.run_all) | Run several methods on one `.h5ad` file, one after another. |
| [`kdb.MethodFailed`](#kdomainbench.MethodFailed) | A method exited with an error. |
