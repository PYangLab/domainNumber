# Tutorials

Each tutorial is a complete analysis on DLPFC sample 151507 (`D1_151507_4k.h5ad`, 4 220 spots,
true k = 7; [Get the data](../installation.md#get-the-data)). [Get started](../quickstart.md)
explains the calls they use.

| Tutorial | What it does |
|---|---|
| [Benchmark the ten methods](benchmark.md) | Runs all ten methods and compares their estimated k, accuracy, domains and cost. |
| [CPU versus GPU](cpu_vs_gpu.md) | Runs CellCharter, DeepST and SpatialDE2 on both devices and compares time and domains. |
