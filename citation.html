    Citation¶

    Cite the kDomainBench paper, the publication of each method you run, the metrics you report, and the dataset.

    The benchmark¶

    The kDomainBench paper is in preparation. This page will give its reference once it is available. Until then, name the repository, https://github.com/PYangLab/domainNumber, the package version (kdb.__version__) and the commit you used (git rev-parse --short HEAD in the cloned folder).

    Reporting a run¶

    To make a result reproducible, report the package version and commit, kmax and the device. The run folder records the rest: run_info.json holds the exact call of the method script (command) and the settings that change a method (env), and packages.txt the package versions of its environment.
